# Muhammad Hashir Abdul Latif | Product Designer

A personal portfolio website for Muhammad Hashir Abdul Latif, a product designer focused on turning complex workflows into clear, human digital experiences.

## Features

- About section and personal introduction
- Selected product design projects
- Skills and tools overview
- Recommendations section with a form for adding new recommendations

## Project Files

- `index.html` - Portfolio page structure and content
- `style.css` - Responsive visual styling
- `script.js` - Recommendation form interaction

## Getting Started

Open `index.html` in a web browser, or serve this folder with any static web server.
